# نطاق التسليم

نسخة ملف أعمال محلية باستخدام PHP وMariaDB وJavaScript دون إطار عمل. تدعم إدارة المعاملات والحالات الأربع والبحث والتصفية والإحصاءات وتصدير CSV وتسجيل الدخول والأدوار الثلاثة وسجل التغييرات.

## القرارات

- فصل المجلد العام عن الإعدادات وأدوات الإدارة.
- حالات ثابتة وترتيب الأحدث أولًا وصفحات من 15 سجلًا.
- جمع التعديل والتدقيق في معاملة SQL واحدة، ورقم إصدار لمنع تعارض التعديلات.
- إنشاء المستخدمين من الطرفية لتبسيط النسخة الأولى.
- قراءة التوقيت بتوقيت UTC وعرضه بتوقيت الرياض.
- تضمين CSP في صفحة HTML وترويسات Apache وAPI؛ ترويسة API وحدها لا تحمي المستند الرئيسي.

## التحقق

راجع TEST-REPORT.md وtest-results.json. تتضمن الملفات صورًا فعلية للواجهة وسير عمل GitHub Actions لفحص الكود واختبارات التكامل على قاعدة مؤقتة. الاختبارات المحلية لا تثبت مرور Actions قبل تشغيله على GitHub.

## خارج النطاق

التسليم لا يتطلب نشر الموقع على الإنترنت. لا توجد واجهة إدارة حسابات أو استعادة كلمات مرور أو مرفقات أو نسخ احتياطي مجدول. لم يتم تدقيق أمني مستقل أو اختبار تحميل. النسخة مناسبة للتجربة ببيانات وهمية؛ لا تمثل اعتمادًا للاستخدام مع بيانات فعلية.

## التعلم لاحقًا

نراجع الواجهة ثم DOM وfetch ثم HTTP وPHP والتحقق، وبعدها PDO وSQL والدخول والصلاحيات والأمان والاختبارات. تُذكر المهارات بحسب ما فُهم وطُبق فعليًا. استُخدم مساعد ذكاء اصطناعي في بناء النسخة؛ لا يُدّعى أن المستخدم كتب الكود بنفسه قبل فهمه.
